# VdkTree 🌳
Общественная карта деревьев Владивостока. MVP v0.1.0.

## Возможности
Карта OpenStreetMap/Leaflet, геолокация, добавление дерева с фото, фильтры по состоянию, карточки, проверка ближайших записей, модерация, адаптивный интерфейс.

## Запуск
```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```
Откройте http://localhost:8000. Python 3.10+.

## Развёртывание на BotHost
Требуется тариф с поддержкой постоянно работающего Python ASGI-приложения и **постоянного диска** для SQLite и фото. Команда: `uvicorn app:app --host 0.0.0.0 --port ${PORT:-8000}` (при необходимости через shell). Установите `DATA_DIR` на постоянный каталог. Если постоянного диска нет — необходимо перенести БД и фото во внешнее хранилище до публичного запуска.

## Важно
Это тестовый MVP, **не публичный релиз**: пока нет авторизации, защиты от спама и настоящей модерации; новые записи сразу видны всем. Перед открытием для жителей обязательны авторизация, очередь модерации, ограничения загрузок, резервное копирование, HTTPS и проверка правовой части. Публичные тайлы OSM имеют лимиты использования; для нагрузки нужен отдельный провайдер.

Код хранится в GitHub; данные и фотографии — на сервере, не в GitHub.
