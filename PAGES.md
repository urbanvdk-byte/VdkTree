# GitHub Pages — VdkTree v0.2.0

1. Откройте Settings → Pages.
2. В Build and deployment выберите Deploy from a branch.
3. Укажите main и /(root), нажмите Save.
4. После публикации откройте https://urbanvdk-byte.github.io/VdkTree/ .

**Важно:** это демонстрация, а не общая база. Деревья и фото сохраняются только в браузере пользователя (localStorage), не видны другим и могут исчезнуть при очистке данных браузера. Для публичного сбора деревьев требуется серверное хранилище, авторизация и модерация.

Backend FastAPI (app.py) остаётся для дальнейшей разработки, но GitHub Pages его не запускает.
