Сложности:
- GitHub Pages не запускает Python/SQLite: вместо серверного сохранения временно использован localStorage.
- Данные между устройствами не синхронизируются, фотографии ограничены 1 МБ; при очистке данных браузера записи исчезнут.
- Публичный сайт не должен позиционироваться как полноценная коллективная база до подключения Supabase и модерации.

Проверки:
- Изменения записаны в GitHub. Проверка работающего Pages-сайта и браузерное тестирование пока не подтверждены.
