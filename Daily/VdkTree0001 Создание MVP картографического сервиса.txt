VdkTree — глава 0001. Создание MVP картографического сервиса
Дата: 2026-11-04
Версия: v0.1.0

Сделано:
- Сервер FastAPI и SQLite для хранения деревьев.
- API списка объектов в пределах карты и добавления дерева.
- Загрузка одного фото с проверкой размера и сигнатуры файла.
- Мобильная карта Leaflet/OpenStreetMap, фильтр состояния, геолокация.
- Добавление дерева по клику на карту, карточки с фото и характеристиками.
- Версия в верхнем правом углу.
- README с запуском и ограничениями размещения.

Проблемы и решения:
- Постоянство данных: SQLite и фото вынесены в DATA_DIR; для BotHost требуется постоянный диск, иначе внешняя БД.
- Публичная модерация и авторизация пока отсутствуют: MVP обозначен тестовым и не должен открываться для массового использования.
- GPS может быть неточным: координаты можно вручную изменить в форме.

Проверки: код добавлен в репозиторий; реальный запуск на BotHost и функциональные тесты ещё не проведены.
Следующий этап: проверка запуска, авторизация, модерация, защита от спама, резервное копирование, продакшн-хранилище.
