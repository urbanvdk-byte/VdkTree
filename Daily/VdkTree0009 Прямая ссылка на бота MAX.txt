VdkTree0009 — Прямая ссылка на бота MAX
Дата: 05.11.2026
Проект/репозиторий: VdkTree (urbanvdk-byte/VdkTree)
Ветка: main
Версия пользовательского интерфейса: v0.4.4

1. Исходная задача
Пользователь передал публичную ссылку одобренного бота:
https://max.ru/id2540275814_1_bot
Требовалось заменить общую ссылку «Перейти в MAX» на прямую кнопку перехода в чат именно этого бота, чтобы новые участники VdkTree могли легко найти мини-приложение и пройти первичную регистрацию.

2. Реализованные изменения
- auth/client.js:
  * В окне первого входа кнопка теперь называется «Открыть бота в MAX» и содержит точную ссылку https://max.ru/id2540275814_1_bot, переданную пользователем, без выдуманных параметров startapp.
  * Вместо общего совета найти бот отображается шаг «Перейдите в чат бота „Деревья Владивостока“ по кнопке ниже».
  * Следующий шаг остаётся прежним: нажать в чате MAX кнопку «Открыть», запустить мини-приложение.
  * Существующие функции проверки подписанных данных MAX на сервере, создание логина/пароля и безопасность входа не менялись.
- tests/test_auth_ui.js:
  * Проверка наличия кнопки «Открыть бота в MAX».
  * Отдельная проверка точного href, равного https://max.ru/id2540275814_1_bot.
  * Остальные сценарии интерфейса первого входа сохранены.
- index.html:
  * В верхнем правом углу увеличена версия с v0.4.3 до v0.4.4.
- Python-сервер, BotHost Dockerfile и SQL базы не менялись.

3. Проблемы и решения
- На промежуточном прогоне GitHub Actions тесты интерфейса сигнализировали о пропаже названия бота в тексте инструкции: при замене общего шага на фразу «наш бот» исходный тест ожидал «Деревья Владивостока».
- Исправлен текст шага: название бота снова показано явно. Тест теперь соответствует пользовательскому интерфейсу, формулировка стала понятнее.
- После исправления GitHub Actions «VdkTree MAX onboarding UI tests» run 42021348129 завершился SUCCESS.
- GitHub Actions «VdkTree authentication checks» run 42021348274 завершился SUCCESS.
- Первичный запуск мини-приложения из реального чата MAX этим изменением не тестировался; проверены код, ссылка и модельные пользовательские сценарии.
