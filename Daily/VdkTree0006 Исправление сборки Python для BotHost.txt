VdkTree0006 — Исправление сборки Python для BotHost
Дата: 05.11.2026
Версия: v0.4.1
Репозиторий: urbanvdk-byte/VdkTree, ветка main.

1. Причина исправления
Владелец прислал лог BotHost: образ собирался из node:20-alpine,
выполнял npm ci/npm install, запуск был CMD ["node","app.py"].
Это неверно: FastAPI-сервер VdkTree написан на Python, не на Node.js.
Указанная в интерфейсе BotHost версия Python 3.11 не меняла фактический
тип автоматически сгенерированного Node-образа; в интерфейсе имелось
прямое предупреждение «На Node-бота не влияет».
Сборка Docker успешно завершалась, но это не означало успешный старт
приложения. Возникало 404 page not found.

2. Что сделано
- В корне репозитория создан Dockerfile: FROM python:3.11-slim,
  WORKDIR /app, pip install по requirements.txt, COPY исходников,
  DATA_DIR=/app/data, PORT=3000, CMD ["python","-u","app.py"].
  Код app.py уже умел слушать 0.0.0.0:$PORT, и его не пришлось
  перестраивать для выполнения контейнера.
- В app.py версия FastAPI и /api/health изменена с 0.4.0 на 0.4.1.
- В index.html справа вверху версия изменена на v0.4.1.
- В BOTHOST.md обновлены инструкции: теперь необходимо установить
  галочку «Использовать собственный Dockerfile» в BotHost и выполнить
  полную пересборку из ветки main. Добавлен раздел диагностики ошибочного
  автозапуска Node.js и проверки /api/health.
- Добавлена .github/workflows/bothost-docker.yml: автоматическая сборка
  реального Python Docker-образа, запуск тестового контейнера и HTTP-проверка
  /api/health с ожиданием JSON {"ok":true,"version":"0.4.1"}.
- Проектная ветка feature/v050-inventory-foundation и PR #1 не изменялись.
  Ни тегов, ни checkpoints не создавалось.

5. Действия пользователя для внедрения
В BotHost → Запуск:
- Главный файл app.py, Python 3.11, порт веб-приложения 3000.
- Включить «Использовать собственный Dockerfile».
- Сохранить и запустить полное обновление/пересборку из main.
- В логе должно появиться FROM python:3.11-slim,
  RUN python -m pip install ..., CMD ["python","-u","app.py"].
- Проверить HTTPS https://vdktree.bothost.tech/api/health.
  Ожидается {"ok":true,"version":"0.4.1"}.
- Не удалять старого бота и данные /app/data, где хранится SQLite.
- Если после пересборки остаётся 404 — проверить домен/маршрутизацию;
  если 502/503 — смотреть именно логи работы контейнера.
