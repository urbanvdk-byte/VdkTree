VdkTree0008 — Удаление логотипа Leaflet с карты
Дата: 05.11.2026
Проект: VdkTree
Ветка: main
Версия пользовательского интерфейса: v0.4.3

1. Цель
По просьбе владельца проекта убрать логотип и ссылку Leaflet из нижнего угла карты, но сохранить обязательную подпись поставщика картографических данных © OpenStreetMap contributors.

2. Что изменено
- Файл index.html: сразу после создания Leaflet-карты вызван map.attributionControl.setPrefix(false);.
- Этот метод отключает стандартный префикс Leaflet в области атрибуции.
- Не изменялись источник карт OpenStreetMap, настройка tileLayer и атрибуция '© OpenStreetMap contributors'.
- Версия в верхнем правом углу страницы увеличена с v0.4.2 до v0.4.3.
- Серверный Python-код, авторизация MAX, база данных BotHost и отдельная ветка инвентаризации v0.5.0 не затронуты.

4. Проверки и проблемы
- Проверено, что новый index.html содержит вызов map.attributionControl.setPrefix(false).
- Проверено, что строка с © OpenStreetMap contributors осталась без изменения.
- Файл после записи повторно считан с GitHub и побайтно в пределах UTF-8 сравнен с запланированным содержимым — результат совпал.
- Ошибок при изменении файла не выявлено.
- Публикация на GitHub Pages выполняется отдельно, поэтому отображение на устройстве пользователя зависит от обновления Pages и кэша браузера.

5. Результат
На карте VdkTree после публикации v0.4.3 должен исчезнуть стандартный логотип/префикс Leaflet. Подпись © OpenStreetMap contributors остаётся. Новых тегов и контрольных точек Git не создавалось.
