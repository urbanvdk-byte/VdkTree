# VdkTree v0.6.0 — настройка общей карты BotHost

## Что нового
- Единая база данных /app/data/inventory.sqlite3: публично видны и предложенные, и подтверждённые записи.
- Деревья: серые/зелёные точки; кустарники: голубые; замечания: независимый красный индикатор.
- Любой вошедший участник может добавить дерево или кустарник, затем оставить замечание. Автор редактирует только свои неподтверждённые точки первые 168 часов.
- Модератор работает в пользовательском интерфейсе: подтверждает предложенные точки, редактирует неподтверждённые точки и собственные площадные объекты.
- Администратор имеет полные права; только ему будет доступна будущая панель массового импорта.
- Газоны, цветники и природные сообщества доступны для добавления модераторам и администраторам как полигоны.
- JPG/PNG/WebP до 5 МБ и до 8 фото на объект в /app/data/photos.

## До обновления
Обязательно сделайте копию постоянной папки BotHost /app/data, включая:
- auth.sqlite3 (пользователи MAX и логины),
- trees.sqlite3 (старая база),
- photos/ (фотографии),
- inventory.sqlite3 (если файл уже существует).

Старую базу trees.sqlite3 новая версия читает и копирует в отдельную БД без удаления исходных записей. Повторный запуск не создаёт дубликаты. Локальные записи из localStorage прежних версий браузера не публикуются автоматически: они остаются видны как локальные пункирные маркеры только в данном браузере.

## BotHost
- Репозиторий: https://github.com/urbanvdk-byte/VdkTree
- Ветка: main (после слияния PR №2)
- Собственный Dockerfile: включено
- Python: 3.11
- Порт: 3000
- DATA_DIR: /app/data
- MAX_BOT_TOKEN: существующий токен бота в переменной окружения BotHost; никогда не публиковать
- Домен API: https://vdktree.bothost.tech

Выполните полное обновление из Git с пересборкой. Не удаляйте и не пересоздавайте бота. Убедитесь, что в логах работы Uvicorn слушает 0.0.0.0:3000.

## Проверка
1. https://vdktree.bothost.tech/api/health → {"ok":true,"version":"0.6.0"}
2. https://vdktree.bothost.tech/api/v2/objects → JSON {"objects":[...]} без авторизации.
3. На https://urbanvdk-byte.github.io/VdkTree/ справа сверху должна быть версия v0.6.0.
4. Через MAX-бота https://max.ru/id2540275814_1_bot откройте мини-приложение; проверьте автоматическую авторизацию. В браузере повторный вход — через ранее созданный логин/пароль.
5. Добавьте дерево и кустарник; проверьте, что они видны с другого устройства.
6. Оставьте замечание к подтверждённому дереву. Зелёный основной статус сохраняется, добавляется красный индикатор.
7. Модератор подтверждает предложенную точку и может закрыть замечание с комментарием.
8. Администратор может изменить подтверждённое дерево и любой площадной объект.
9. После перезапуска BotHost записи и пользовательские сессии сохраняются.

## Ограничения
- Карта загружает максимум 5000 объектов за запрос; кластеризация и постраничная загрузка — позднее.
- Оценка самопересечений и геодезической площади полигонов — следующий этап.
- Массовый Excel/CSV импорт и экспертные поля — следующие этапы.
- Автоматические тесты не могут заменить реальную проверку MAX на устройстве.
- Правила RLS/полномочий применяются сервером Python, не только интерфейсом.
- Утилиты sqlite3 в минимальном Python-образе может не быть; при необходимости используйте модуль Python sqlite3 в защищённом терминале BotHost.
